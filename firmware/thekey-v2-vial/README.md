# The Key V2 with Vial

Keymap for the Vial fork (https://github.com/vial-kb/vial-qmk): keys send F13/F14/F15, lighting is the QMK RGB light
(default: static rainbow gradient). Copy these files to `keyboards/drop/thekey/v2/keymaps/trascrittore/` in vial-qmk and run
`make drop/thekey/v2:trascrittore`. Flash like the VIA firmware (see ../thekey-v2/README.md) and configure with the Vial app
(https://get.vial.today). Unlock for dangerous operations: hold the first and last key.
Only a few light effects are kept, so the firmware fits the atmega32u4 (96% full).
